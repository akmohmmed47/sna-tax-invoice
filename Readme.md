# sna-tax-invoice
Professional Tax Invoice Template for SNA PACKAGING INDUSTRIES - Sri Lanka

## 📄 About
Fully editable, auto-calculating tax invoice template built for SNA PACKAGING INDUSTRIES, Sri Lanka.

## ✨ Features
- ✅ **Fully Editable** — Click any field to type directly
- ✅ **Auto Calculation** — Qty × Price, Totals, VAT @ 18% auto-computed
- ✅ **Sri Lankan Format** — TIN, Address, Date, Invoice No. standard format
- ✅ **Save as PDF** — One-click clean PDF download
- ✅ **Direct Print** — Browser print dialog ready
- ✅ **Clean & Clear Design** — Black text, light watermark, no highlight background
- ✅ **A4 Perfect Fit** — Fits exactly on one A4 sheet
